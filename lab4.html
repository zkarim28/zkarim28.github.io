The PDF contradicts itself in places. Ask a TA if unsure.
  • Active instructions use kernel 6.18.57 + patch 6.18.56-rt7. Text on p.26-27 still says 6.1.93 / 6.1.92. Follow 6.18.57 / 6.18.56-rt7.
  • The git checkout 4ce3961… step is struck through. Skip it unless a TA says otherwise (PDF: "Please ask if you are unsure").
  • Compile time is 2.5 hours on p.12/20/21 and 90 minutes on p.22. Plan for 2.5 h.
  • The USB workaround in cmdline.txt is printed dwc_otg.fig_enable=0 …. I believe the real parameter name is fiq, not fig (and on Trixie the file is /boot/firmware/cmdline.txt). Confirm with a TA.
  • PDF says "type, don't paste" for the clone command. The PDF's flags use en-dashes (–m); type plain hyphens (-m) or they fail. The copy buttons here are safe.
