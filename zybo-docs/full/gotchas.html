Gotchas

Things to remember for next time that are not tied to one error.

Vivado

  • Computer name must be ASCII (I-01). Check $env:COMPUTERNAME after any PC rename or restore.
  • 260-byte path limit: package the IP from a short folder; Vivado doubles the run path. (I-02)
  • Never hand-edit the .xpr while Vivado is open; set ip_repo_paths from the Tcl console.
  • After changing IP source: Re-Package → refresh catalog → Report IP Status → Upgrade → validate → regenerate outputs → synth/impl → export XSA.
  • The VLNV vendor is xilinx.com; get_ipdefs xilinx:... finds nothing.
  • Do not type grep in the Tcl console (it goes to the shell and chokes on regex); use an external shell.
  • The generated driver Makefile may contain ($wildcard ...) (I-07); save_bd_design_as needs an argument, use save_bd_design.
  • Reopening a packaged IP: Edit IP from the wizard opens a project with no sources, because that project's own IP-repository list doesn't include the IP's folder yet. Fix it there (Tools → Settings → IP → Repository, add the folder), then reopen the IP from the IP Catalog → Edit in IP Packager — that opens a second project that actually has the sources.

Checking a bitstream is real

  • Look at the modified times in synth_1 and impl_1 and grep the run logs for lorenz before trusting a bitstream. (I-12)
  • write_bitstream alone reuses the last routed checkpoint; if the block design changed, reset_run synth_1 first.
  • PL address that gives Fault status 0x8 / data abort = nothing decodes it = wrong bitstream or wrong address.

IP and arithmetic

  • Format: 27-bit signed, 1 sign + 6 integer + 20 fractional bits (written Q6.20; older notes say Q7.20). value = raw / 220, range about ±64.
  • DT (0x20) is a raw right-shift count, not fixed point: step = 2−dt.
  • One Euler step per rising edge of CTRL bit 0: write 1 then 0. load is CTRL bit 1: write 1 then 0. STATUS.done is a one-clock pulse.
  • All writable registers read 0 after reset; write parameters and load before stepping.
  • The wizard's "Number of Registers" only sizes the generated template (I entered 7 → 5-bit bus; minimum is 4). Growing the register map later widens the address bus (5 → 7 bits here) and the instance in the block design must be upgraded (I-03).
  • Base address is 0x43C30000 in this project (it was 0x43C10000 in the simplified attempt-1 design).

Vitis / PS

  • Update Hardware Specification → Clean → Build platform → check xparameters.h (file date!) before building the app (I-06).
  • The BSP re-extracts the driver files from the XSA; fix the IP source and re-export, not just the BSP copies.
  • The app builds without the Lorenz macro (guarded by #ifdef) — a missing menu/plot means a stale BSP.
  • Digilent's project files carry D:/Zybo-Z7-SW paths; fix before Create Boot Image (I-10).
  • Program Device warning 'executables ... doesn't exist' is harmless when you run the app separately.
  • xil_printf has no float support; use snprintf. Source files use CRLF — keep it when editing with sed.
  • Serial 115200 8N1; open the terminal before running or early prints are lost.
  • Pixels are 3 bytes in order R, B, G; flush the D-cache after drawing or the VDMA shows stale pixels.

Board and boot

  • JP5: JTAG for Program/Run from Vitis, SD to boot from card. PL configuration is volatile.
  • Create Boot Image writes to _ide/bootimage/BOOT.bin, not to the old Debug/sd_card/ folder.
  • HDMI cable goes to the TX (OUT) connector.

Repo

  • GitHub blocks files over 100 MB; keep *.zip, *.bit, *.xsa, *.runs, .metadata, _ide, Debug out of git (I-17).

Earlier-attempt lessons

  • A hand-simplified block design (attempt 1) cost days; start from the vendor's known-good archive and add one thing at a time.
  • Two IPs can ship different files with the same VHDL entity name (SyncAsync) → black box (I-13).
  • A half-saved interconnect in design_1.bd shows up as unconnected clocks on internal coupler pins (I-09); back up the BD before scripted repairs.
  • Two parallel chat sessions edited the same files on 09-22; some edits (the dirty-rectangle flush) did not survive — check the tree, not the transcript.
