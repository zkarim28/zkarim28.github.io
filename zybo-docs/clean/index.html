Lorenz DDA on Zybo Z7-10 — clean build

How the Lorenz-attractor plotter was built on the Zybo Z7-10, following only the flow that worked: a fresh Digilent HDMI demo plus a custom AXI-Lite Lorenz IP and a small PS program.

Scope. Starts at the second restart from a fresh Digilent demo. Earlier attempts (a hand-simplified design, then a first fresh restart) were abandoned; only the lessons that still matter are kept, as prerequisites and gotchas.
Result. A Lorenz attractor computed in the FPGA fabric, plotted by the ARM core as three phase-plane projections plus a parameter panel on a 1920×1080 HDMI display; UART keys change speed and parameters; the board runs the project from an SD card just by powering it on.

Video walkthrough

A screen recording of the whole project flow, focused on how the tool interfaces are used. Watch it once for orientation, then follow the build-log pages step by step.

Architecture at a glance

Highlighted boxes are new. Control path: PS → GP0 → interconnect → Lorenz IP (write parameters, pulse step, read x/y/z). Video path: the CPU draws into DDR; the VDMA streams it through the stock Digilent TX chain to HDMI. The PL only computes numbers; the CPU draws the picture.
